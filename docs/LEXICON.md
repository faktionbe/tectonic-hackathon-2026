# Domain lexicon

Domain concepts and entities for this project. Read this when a term is unclear; update it whenever you
learn a concept that is not captured here yet.

## User

A platform account that can sign in. Authentication identity only (name, email, password, role). Not the same as a Profile.

## Profile

A person the bank studies: financial literacy, household, income, declared balance-sheet snapshot, goals, and service interests. Independent from User; no login credentials. Line-item spending will live on Transactions later.
